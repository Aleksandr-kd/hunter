# Инструкция: правка данных сроков охоты и добавление регионов

Все данные сроков хранятся в таблице **`hunting_seasons`** в Supabase.
Правишь таблицу — приложение при следующем запуске (синхронизации) подтянет изменения.

## Где открыть

1. Консоль Supabase → **Table Editor** → таблица `hunting_seasons`.
2. Либо **SQL Editor** для массовых правок (шаблон ниже).

## Формат одной строки (колонки)

| Колонка | Пример | Назначение |
|---|---|---|
| `region_id` | `krasnodar` | id региона |
| `region_name` | `Краснодарский край` | название |
| `resource` | `Пернатая дичь` | категория (каталог фиксирован) |
| `season` | `Осень` | Весна / Лето / Осень / Зима |
| `species` | `Вальдшнеп` | вид дичи |
| `open_date` | `15.08` | начало (формат ДД.ММ) |
| `close_date` | `16.01` | конец |
| `restrictions` | `только с собаками…` | ограничения (можно пусто) |
| `zone` | `Все` | зона охоты (можно пусто) |
| `date_rule` | `4-sat:09` | плавающая дата открытия: N-й день недели месяца (mon..sun). Примеры: `4-sat:09` — 4-я суббота сентября, `3-sat:08` — 3-я суббота августа. Клиент сам вычисляет дату для каждого года; `open_date` оставляет как подсказку. Пусто — фиксированная дата |
| `close_rule` | `4-sun:11` | то же для даты закрытия (например 4-е воскресенье ноября). Пусто — фиксированный `close_date` |

## Редактировать только Краснодарский край

1. **Table Editor** → фильтр по `region_id = 'krasnodar'`.
2. Меняй ячейки (сроки, ограничения, зоны) **напрямую в строках** → **Save**.
3. Перезапусти приложение → данные обновятся.

## Добавить новый регион (например, Адыгея)

1. **Table Editor** → **Insert row**.
2. Заполни те же колонки, но:
   - `region_id` = уникальный код, например `adygea`
   - `region_name` = `Республика Адыгея`
3. Добавь ВСЕ строки по региону (каждая комбинация ресурс + сезон + вид = отдельная строка).
4. Готово: каталог регионов в приложении строится автоматически из записей
   `hunting_seasons` — новый регион сам появится и в фильтре «Регион»
   (Сроки охоты), и в выборе «Мой регион» (Дополнительно → уведомления).
   Правка кода не нужна.

## Быстрый способ залить много строк (SQL)

В SQL Editor вставь INSERT по шаблону:

```sql
insert into hunting_seasons
(region_id, region_name, resource, season, species, open_date, close_date, restrictions, zone)
values
('adygea', 'Республика Адыгея', 'Копытные животные', 'Осень', 'Кабан', '01.06', '28.02', NULL, 'Все');
```

## Правило вида с разными сроками

Если у вида несколько периодов (например, вальдшнеп с собаками 15.08-16.01 и без 15.08-31.12) —
это **две отдельные строки**, обе показываются пользователю. НЕ объединяй их в одну.
