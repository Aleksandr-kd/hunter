# План: Документы, уведомления, настройки

## Проблема
1. **Даты документов не сохраняются** — хранятся в локальном списке `_documents` в памяти, теряются при перезапуске
2. **Уведомления в настройках общие** — один переключатель «Уведомления» для сезонов и документов
3. **Уведомления о сезонах не реализованы** — только баннер синхронизации дневника
4. **Дублирование** — пункт «Документы» в MoreScreen дублирует кнопку в профиле

## Шаг 1: Сохранение дат документов в SharedPreferences

**Файл:** `lib/screens/documents_screen.dart`

- Вынести список документов в `State` с загрузкой из `SharedPreferences` при `initState`
- Ключ: `'documents_expiry'` — JSON-список `{title, expiry}` (expiry как ISO string)
- При `_pickDate` и `_clear` — сохранять/удалять из SharedPreferences + вызывать `notifyListeners()`
- Удалить `setState` из `_schedule` (не нужно — уведомления уже запланированы)

## Шаг 2: Разделить уведомления в настройках

**Файл:** `lib/screens/profile_screen.dart` (класс `SettingsScreen`)

- Заменить один `SwitchListTile` «Уведомления» на два:
  - `SwitchListTile` — «Уведомления о сезонах» + subtitle: «Напоминания за 7 и 3 дня до начала/конца сезона»
  - `SwitchListTile` — «Уведомления о документах» + subtitle: «Напоминания за 30, 14 и 3 дня до истечения»
- Значения хранить в `SharedPreferences` (ключи: `notifications_seasons`, `notifications_documents`)
- Загружать при `initState`, сохранять при изменении

## Шаг 3: Уведомления о сезонах

**Файл:** `lib/providers/seasons_provider.dart`

- При загрузке/обновлении данных проверять ближайшие сезоны (открытие/закрытие в течение 7 дней)
- Если уведомления о сезонах включены — планировать уведомления через `NotificationService`
- Уведомления:
  - «Сезон открывается [дата]» — за 7 и 3 дня до открытия
  - «Сезон заканчивается [дата]» — за 7 и 3 дня до закрытия
- ID уведомлений: `season_open_{resourceId}_{season}` и `season_close_{resourceId}_{season}`
- Ресурс ID можно генерировать из `resource + season + regionId`

## Шаг 4: Убрать документы из MoreScreen

**Файл:** `lib/screens/profile_screen.dart` (класс `MoreScreen`)

- Удалить `_MoreTile` с пунктом «Документы» (иконка `Icons.verified_user_outlined`)
- Оставить только: Настройки, Подписка, Тариф (dev), О приложении

## Порядок выполнения
1. Шаг 1 — сохранение документов
2. Шаг 2 — разделение уведомлений
3. Шаг 3 — уведомления о сезонах
4. Шаг 4 — убрать из MoreScreen
