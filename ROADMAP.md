# Дорожная карта проекта «Помощник охотника»

> Этот файл — единый путеводитель по проекту: что делаем и что уже готово.
> Галочки `[x]` отмечают выполненные пункты. Обновляю его на каждом этапе.

**Продукт:** мобильное приложение для охотников России — «Охотник» (Android → iOS)
**Стек:** Flutter (Dart), SQLite, Provider, RuStore (платежи + реклама), Supabase (бэкенд)
**Репозиторий:** https://github.com/Aleksandr-kd/hunter

## Модель монетизации (фиксируем)

| Фича | Free 0 ₽ | Premium 150 ₽/год | Max 300 ₽/год |
| :--- | :---: | :---: | :---: |
| Реклама (баннер внизу) | ✅ да | ❌ нет | ❌ нет |
| Регионы сроков охоты | 1 (свободное переключение) | 1 | все |
| Дневник | до 10 записей | безлимит | безлимит |
| Экспорт PDF/CSV | — | ✅ | ✅ |
| Резервная копия (SD/файл) | — | ✅ | ✅ |
| Тёмная тема | — | ✅ | ✅ |
| Калькулятор законности | — | — | ✅ |
| Расширенная статистика | — | — | ✅ |
| Напоминания (сезон/документы) | базовые | ✅ | ✅ |
| Триальный период 7 дней | — | ✅ | ✅ |

Логика: **Max включает всё из Premium**. Автоповышение 150 → 300 через сервер (при покупке 300 активная 150 отменяется автоматически).
